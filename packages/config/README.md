# @nexora/config

Shared presets so every app follows the same rules.

| Export | Use |
| --- | --- |
| `@nexora/config/eslint` | Flat ESLint config (TypeScript recommended rules) |
| `@nexora/config/tsconfig/base` | Strict TypeScript base |
| `@nexora/config/tsconfig/nextjs` | Base + Next.js settings for `apps/web` |
| `@nexora/config/tsconfig/nestjs` | Base + decorators and CommonJS output for `apps/api` |
| `@nexora/config/prettier` | Prettier options |
